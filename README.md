# FULL HIPERTROFIA (APK)

Proyecto Android que carga `app/src/main/assets/index.html`.

- Para cambiar la app web: reemplaza `app/src/main/assets/index.html`.
- Para compilar: en GitHub, pestaña **Actions → Build APK → Run workflow**.
  El APK queda en **Artifacts → FullHipertrofia-APK** (`app-debug.apk`).
